# Reusable Active Learning & Academic Feedback Standard v1.0

Status: design baseline for GPMS and adaptation to other courses. Not a claim of validated learning outcomes.

## 1. Course configuration
Each course must define audience, prerequisites, course learning outcomes (CLOs), scope, session duration, accessibility and device constraints, instructor-approved source register, assessment policy, privacy classification and evidence retention. Do not copy GPMS subject content into another course without academic review.

## 2. Content unit contract
Every unit has: unit ID; mapped CLO; prerequisite; learning objective; evidence-backed explanation; worked and counterexamples; guiding questions; authentic task; learner-generated artifact; rubric dimensions; feedback rules; revision opportunity; transfer task; reflection; references; version and academic owner. Distinguish sourced facts, instructor-authored examples and synthetic scenarios.

## 3. Active learning quality gate
A task must require learners to think or decide before receiving answers, apply concepts to a case, articulate reasoning, produce observable evidence, receive actionable feedback, revise or defend a decision, transfer learning to a new situation, and reflect using before/after evidence. Not all activities need all methods, but every unit must provide meaningful learner action and formative assessment.

## 4. Expandable activity catalog
Case-based learning; problem-based learning; project-based learning; inquiry; Think–Pair–Share; peer instruction; jigsaw; debate with evidence; concept mapping; problem tree; gallery walk; role play; simulation; decision branching; design studio; data interpretation; error analysis; objective repair; indicator matching; rubric clinic; peer critique; collaborative annotation; field observation; microteaching; teach-back; portfolio defense; retrieval practice; exit ticket; reflective comparison. Select by CLO, learner needs, time and evidence, not novelty. Provide individual and low-bandwidth alternatives.

## 5. Assessment design
Pre-test diagnoses prior knowledge; post-test measures learning using aligned but non-identical items where possible; performance tasks assess application; revision evidence captures growth. Build test blueprints by CLO and cognitive demand; check item accuracy, ambiguity and accessibility. Do not infer competence from quiz score alone. Instructor sets weights and passing criteria. A quiz is optional where performance evidence is more appropriate.

## 6. Feedback and revision
Sequence: original learner draft -> learner self-analysis -> peer discussion -> rubric-grounded system findings -> precise red-highlighted proposed text changes -> learner accept/edit/reject with reason -> revised draft -> re-analysis -> linked-impact review. Never overwrite original. Red alone must not convey meaning; label added/deleted/replaced text. Rule-based feedback must be identified as such, not described as semantic AI.

## 7. Traceability
Use stable IDs for Problem, Objective, Indicator, Activity, Output, Outcome, Assessment, Instrument, Rubric, Evidence and Report. A changed objective creates an impact review for linked entities. Update display references automatically, propose substantive changes for confirmation, preserve historical evidence. No retroactive rewrite of completed assessment.

## 8. Teaching Studio
Separate instructor console from projector-safe presentation. Phases: engage -> individual think -> small-group discuss -> anonymous gallery -> instructor-controlled reveal of feedback -> revise -> transfer -> exit ticket. Instructor selects work to display. Hide identities and grades by default; require explicit authorization to display identifying work. Support pausing projection and moderation.

## 9. Privacy and release gates
Synthetic-only prototype until authentication, authorization, secure storage, consent/notice, retention and instructor governance are verified. No production or real-student claims without end-to-end testing. Version content, rubrics, quiz items and evidence. Gate release on build, functional testing, accessibility and academic review.

## 10. Reuse procedure
Copy this standard, then author a course-specific Course Configuration, CLO–Activity–Evidence Matrix, Activity Bank, Assessment Blueprint and Instructor Guide. Adapt activity types freely; preserve academic ownership and privacy safeguards.
